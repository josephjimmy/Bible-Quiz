# Malayalam Bible Quiz

27 interactive Malayalam quizzes based on Matthew 16–28 and MCP-retrieved POC Catholic Bible text.

- `quizzes/25/`: 7 unit quizzes, 25 questions each (original questions retained).
- `quizzes/50/`: 7 expanded unit quizzes, 50 questions each.
- `quizzes/30/`: 13 chapter quizzes, 30 questions each. Relevant quizzes include independently verified POC Old Testament reference questions.

All quizzes use automatic checking, accessible matching dropdowns, scoring, reset, and a question-number jump menu. No build step, server, external libraries, or remote resources are required.

## GitHub Pages setup

Upload these files to the repository root. Under **Settings → Pages**, choose **Deploy from a branch**, select the repository default branch and **/(root)**, then save. Use the URL displayed by GitHub after the deployment succeeds. Preserve the folder structure.

## Content

The original 25-question collection is recovered from the preserved original items in the expanded collection (13 MCQs, 7 option-based blanks, 2 matching, 3 true/false). Question wording, answer options, and source evidence are retained. Hosted copies share the latest interface and home-page navigation.
