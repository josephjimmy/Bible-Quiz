# Malayalam Bible Quiz

The home page now displays 13 consolidated chapter quizzes for Matthew 16–28. Questions are selected from the prior 25/50-question unit collections and 30-question chapter collection, removing exact copies and reviewed repeated facts. Counts vary by chapter. The original collections remain in the repository as an archive, without home-page links.

All chapter quizzes retain automatic answer checking, matching dropdowns, scoring, review, reset, and a question-number menu. POC source evidence and verified Old Testament reference questions are retained.
